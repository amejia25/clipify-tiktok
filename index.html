Clipify AI - TikTok Integration

Personal integration for publishing short-form videos from the Clipify AI desktop application to an authorized TikTok account.

About this integration

This project is an independently configured integration of the open-source Clipify AI desktop application.

Its goal is to allow an authorized user to upload videos and captions to TikTok through the Content Posting API.

TikTok publishing functionality is under development and subject to TikTok approval.
